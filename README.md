# spark-trustworthiness-estimator

This tool was created during my bachelor's thesis on "Automatically Estimating the Trustworthiness of Wikipedia Articles". It uses Wikipedia dumps as "training data" to first estimate the trustworthiness of external sources. Then, for any arbitrary Wikipedia article, the program estimates the trustworthiness based on the trustworthiness estimates of the external sources referenced by the article.
